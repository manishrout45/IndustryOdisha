# NewsPortal Client

Complete React + Vite frontend for the news portal project.

## Features

- Responsive public news homepage
- Article detail view with comments
- Category browsing
- Search view
- Login and register panel
- Contact/about pages
- Editorial dashboard with stats and publishing queue
- Sample newsroom data in `src/data/news.js`

## Commands

```bash
npm run dev
npm run build
npm run preview
```

If the global `npm` installation on the machine is broken, run Vite directly:

```bash
node node_modules/vite/bin/vite.js
node node_modules/vite/bin/vite.js build
```
